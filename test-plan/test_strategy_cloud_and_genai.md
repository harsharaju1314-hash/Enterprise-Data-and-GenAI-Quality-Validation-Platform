# Quality Engineering Strategy: Cloud Data & GenAI

## 1. Cloud ETL Data Quality Strategy
To validate multi-stage cloud pipelines without relying on brittle black-box assertions:
1. **Source Layer (Bronze)**: Validate row counts, headers, encoding, delimiter consistency.
2. **Transformation Layer (Silver)**: PySpark unit validations for deduplication, datetime parsing, enum categorization, and null-handling.
3. **Serving Layer (Gold)**: Aggregated metric reconciliation against raw source formulas.
4. **SQL Automated Harness**: 19 automated SQL queries validating 7 core data dimensions.

## 2. GenAI Quality Engineering Strategy
Traditional software testing relies on deterministic assertions ($f(x) = y$). GenAI and RAG systems require multi-dimensional evaluation:
1. **Retrieval Verification**: Measuring precision and recall of retrieved chunks against golden source documents.
2. **Groundedness & Faithfulness**: Verifying that every statement generated by the LLM is directly evidenced in the retrieved context.
3. **Hallucination Prevention**: Feeding adversarial out-of-domain queries to confirm the model explicitly refuses instead of fabricating facts.
4. **Prompt Injection & Safety Guardrails**: Testing jailbreaks, system prompt overrides, and unauthorized SQL exfiltration attempts.
5. **Prompt Variation Robustness**: Testing syntactic variations of the same intent to ensure consistent answers.
6. **Continuous Regression Gate**: Automated CLI runner that re-evaluates the golden benchmark suite before deploying prompt or chunking updates.
